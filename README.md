# GUI FLIX : application Android

Cette application affiche le site GUI FLIX en plein écran, sans barre d'adresse.
Quand tu modifies le site, l'application est mise à jour toute seule.

## Obtenir l'APK
1. Envoie tous ces fichiers sur un dépôt GitHub (dossier `.github` compris).
2. Onglet **Actions**, puis **Construire l'APK GUI FLIX**, puis **Run workflow**.
3. Attends 5 à 10 minutes, ouvre l'exécution terminée et télécharge **guiflix-apk** (en bas de la page).
4. Décompresse le zip : le fichier `app-debug.apk` est l'application.
